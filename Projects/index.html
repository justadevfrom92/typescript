TypeScript Mastery Roadmap

Run npm run build first. Lessons 01–05 and 13–17 run in Node; the browser projects open below.

  1. 01–05 · Language core — run with node 01-BasicTypes/dist/main.js etc.
  2. 06 · Posts Browser — typed DOM + fetch, no JSX
  3. 07 · Weather Dashboard — first TSX app, hooks, effects, abort
  4. 08 · Pokémon Explorer — paging, search, request cache
  5. 09 · Currency Converter — validated forms, typed errors
  6. 10 · Photo Gallery — plain JSX + JSDoc checked by tsc
  7. 11 · Task Board — reducer + action unions, localStorage
  8. 12 · Team Directory — layers, DI, store, hash router
  9. 13–17 · Advanced language — functions, advanced types, modern features, declarations, compiler flags (run in Node)
  10. 18 · Typed Workers — Web Worker with a typed message protocol
  11. 19 · Typed API Client — endpoint type map, path params, error unions
