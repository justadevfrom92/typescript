TypeScript Mastery Roadmap

Every project is a TypeScript page compiled by tsc. Lessons show live examples; apps use real public APIs.

  1. 01 · Basic Types — annotations, literals, tuples, unknown, never
  2. 02 · Unions & Narrowing — discriminated unions, type predicates
  3. 03 · Generics — constraints, keyof, generic classes
  4. 04 · Mapped & Utility Types — Partial, Pick, mapped and conditional types
  5. 05 · Classes & Interfaces — abstract classes, #private, typed events
  6. 06 · Posts Browser — typed DOM + fetch, no JSX
  7. 07 · Weather Dashboard — first TSX app, hooks, effects, abort
  8. 08 · Pokémon Explorer — paging, search, request cache
  9. 09 · Currency Converter — validated forms, typed errors
  10. 10 · Photo Gallery — plain JSX + JSDoc checked by tsc
  11. 11 · Task Board — reducer + action unions, localStorage
  12. 12 · Team Directory — layers, DI, store, hash router
  13. 13 · Functions Deep Dive — overloads, this, assertion functions
  14. 14 · Advanced Types — branded, recursive, variadic, NoInfer
  15. 15 · Modern Language Features — generators, symbols, using, decorators
  16. 16 · Declarations & Modules — .d.ts, enums, namespaces, augmentation
  17. 17 · Compiler & Strictness — every strict flag, reading errors
  18. 18 · Typed Workers — Web Worker with a typed message protocol
  19. 19 · Typed API Client — endpoint type map, path params, error unions
