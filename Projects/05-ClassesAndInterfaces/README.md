# 05 · Classes & Interfaces

Interfaces, `implements`, abstract classes, `public`/`protected`/`private` vs runtime `#private` fields, parameter properties, getters, static members, `override`, custom error classes and a generic `TypedEmitter<Events>`.

```bash
cd Projects
npm run build
npm run serve
# open http://localhost:<port>/05-ClassesAndInterfaces/
```

The page runs every example in `src/main.ts` in your browser and shows each result, or the error it throws, next to the code.

**Try it:** call `savings.emit("deposited", …)` from `main.ts` — `protected` blocks it.
